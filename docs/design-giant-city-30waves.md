# DEAD SIGNAL · 巨人城模式 —— 30 波防守设计文档

状态：已实现（2026-10-19）。本文档定义玩法与数值，M0–M7 及追加的武器五槽、传送改键均已落地；文末列出与现有代码的技术差距（现全部完成）。实现进度与验收细节见 `docs/implementation-plan.md`。

已确认的四个核心决策：

1. **一关 = 一波**：同一张大地图上连续 30 个波次，波间刷补给。第 15 / 20 波为泰坦，第 30 波为巨型泰坦。
2. **复活币**：玩家专属资源。倒地后消耗 1 币 → 在**当前阶段的前线复活点重生**（不是原地），无敌 5 秒，跑回归队；币为 0 时再次倒地 = 团队失败。初始 30，开局前可设置。（v1 曾定"原地复活"，已按新需求改为退回上个点。）
3. **AI 队友**：3 名机器人，火力辅助 + 自动守点，无限复活；怪物仇恨不再锁定玩家一人。
4. **落地范围**：本文档先行，确认后再排实现。

## 二、模式总流程

菜单模式二选一（已确认）：**巨人城 · 30 波防守**（本模式，48→96×48 长图、队友、复活币）与 **隔离区 07 · 5 波练习**（现有玩法原样保留，无队友/复活币）。以下流程描述巨人城模式。

```
开局设置（难度 / 复活币数量）
→ 30 个波次连续防守（波间 15 秒补给窗口）
→ 第 15 / 20 波：泰坦
→ 第 30 波：巨型泰坦
→ 击杀关底 → 胜利结算（分数 / 用时 / 复活币余量 / 爆头率）
```

- 波次胜利条件：场上敌人 + 待生成敌人为 0。
- 失败条件（任一）：玩家倒地且复活币为 0；或 BOSS 计时模式启用时超时（默认关闭）。
- 3 名队友全程阵亡不导致失败，仅减输出。

## 三、地图：长条形废墟（可行走火车版）

现有地图是 48×48 方形平地，本模式需要扩展为 **96×48** 的纵向长条图（Z 轴 -48..48），参考巨人城废墟的三段式结构：

```
        [北通道口]  [火车头/北端]  [南通道口]
   ┌──────┬────┴┴┴┴────┬──────┐
   │ 西侧通道 │   中央平台   │ 东侧通道 │        ← 怪物三条进攻路线
   │ (宽8m)  │  (集结/输出)  │ (宽8m)  │
   ├──────┤   火 车 车 厢   ├──────┤
   │ 掩体区  │  (可行走车顶)  │ 掩体区  │        ← 车厢中段，两侧斜坡上车顶
   ├──────┼───────────┼──────┤
   │      我方出发区 / 复活点 A、B        │        ← 南端，玩家与队友出生
   └───────────────────────┘
```

关键点位与规则：

| 点位 | 功能 | 风险 |
|---|---|---|
| 火车车顶 | 视野覆盖全图，特殊武器/火力压制好阵地 | 自爆体沿斜坡冲顶自爆；雾散体在车顶南端放雾后车顶变盲区 |
| 箱顶栈道 / 跨通道横桥 | 不回地面横穿全图、拉侧翼枪线、换位的快速通道 | 桥面只有 0.24m 薄板无遮体，自爆体冲顶后在栈道上同样能起爆 |
| 中央平台 | 集合输出、躲泰坦冲刺的绕柱区 | 自爆体贴身高危 |
| 西/东通道 | 两条主要刷怪路，队友各守一条 | 裂魂者击退在通道内可能把队友推入口 |
| 北通道口 | 第 25 波后第三条刷怪路 | 三面受敌 |
| 前线复活点 A/B/C | 出发区两侧为 A；B 在中央平台南缘，C 在火车南端，随波次阶段解锁（见第四节）。玩家耗币复活与队友无限重生共用当前阶段最近的复活点 | — |

车顶可行性规则：车顶高 3.2m，两条 15° 斜坡可行走；实现上需要给平台加顶面碰撞（现状只有 XZ 障碍，见第十节）。

高台网络（2026-10-15 追加）：掩体区的六只集装箱**箱顶可行走**（盖板 3.36/3.46/3.51m），两侧箱顶由纵向栈道连成两条带，两座 **3.6m 跨通道横桥**把西带—车顶—东带串起来，玩家不用回地面就能横穿全图。上桥路线仍只有南端两条斜坡：斜坡 → 装载甲板(3.2) → 车厢顶(3.2) → 横桥(3.6) → 箱顶。怪物按"地面单位"规则（`fromY = 0`）依旧上不了任何高台，薄桥面板底 3.36m 净空可直接穿过；高台威胁仍由自爆体冲顶与雾散封视野承担，横桥不是安全点——`segmentClear` 高度感知，地面射手能打到你。

## 四、小队与复活系统

### 玩家

- 血量 100，护甲无。倒地 = 血量归零，进入 **60 秒**濒死读条（期间小地图显示，队友自动向你靠拢吸引火力）；读条走完 = 团队失败。
- 濒死中按键消耗 1 复活币 → **退回上个点**：在当前波次对应的前线复活点（见下表）重生，恢复 50 点生命、**无敌 5 秒**（免疫伤害与击退），需要自行跑回战场。
- 复活点随战线推进（阶段解锁）：

| 波次 | 前线复活点 | 回归路程 |
|---|---|---|
| 1–9 | A · 南端出发区 | 长（前期怪少，风险低） |
| 10–24 | B · 中央平台南缘 | 中 |
| 25–30 | C · 火车南端车顶下 | 短（后期压力波不宜长跑图） |

- 币为 0、或放弃读条、或读条走完 → 团队失败，直接结算（显示到达波次）。
- **G 传送归队**（2026-10-19 改版）：按键从 F 改为 **G**，**取消 20 秒窗口与一切次数/冷却限制**——只要没倒地、任意时刻按都能传。原本只是"复活后投奔队友"，现在同时承担**脱困**职责：卡在箱顶缝隙、集装箱之间、车顶等走不出来的位置时，G 是唯一的自救键。（曾短暂定在 Q，因 Q 已是"Tab 选队友后的指令循环"而换到 G；R 保留给换弹。）
  - 落点：最近存活队友朝玩家一侧 1.3m 的同层站位；队友全部阵亡或练习模式无队友时，回落到当前防守岗位点，保证永远有地方可去。
  - 落地**不给无敌**：G 不限次数，再送 5 秒无敌等于连按刷无敌；复活本身给的 `guard` 秒无敌不变。
  - HUD：`#rally` 常驻提示条（不再显示倒计时），小地图常驻高亮当前落点菱形。
- 开局设置：复活币 0–99，默认 30。设为 0 视为硬核模式，最终得分 ×1.5，G 传送规则不变（传送不花币）。

### AI 队友（3 名）

| 代号 | 武器 | 行为定位 | 属性 |
|---|---|---|---|
| 尖刀 | 步枪 | 主动推进，清车顶与通道口的高威胁目标 | HP 120，DPS ≈ 玩家基准 18% |
| 盾卫 | 步枪+近战 | 守中央平台，吸引近战仇恨 | HP 180，DPS ≈ 14%，自带 30% 减伤 |
| 游骑兵 | 狙击 | 守车顶/平台，优先高威胁目标 | HP 90，DPS ≈ 20%，对自爆体/雾散体/裂魂者优先开火 |

通用规则：

- **指令系统**：Tab 循环选中队友（头顶标记+准星靠近提示），Q 在其三种模式间切换（传送键 2026-10-19 挪到了 G，Q 保持给指令）：
  - **守点**：死守分派岗位（尖刀-通道口/盾卫-中央平台/游骑兵-车顶），仅追击 10m 内目标；
  - **跟随**：贴玩家 4–8m 机动，跟随玩家仇恨；
  - **自由**：主动清剿，优先打高威胁（自爆/雾散/裂魂）与车顶/斜坡敌人。
  - 默认配置：盾卫=守点（平台）、游骑兵=守点（车顶）、尖刀=自由。指令在下达后 1.5 秒内生效，波次进行中可改。
- 队友不消耗复活币：阵亡后 5 秒在最近的复活点重生，跑回原岗位或玩家身旁（按当前指令）归队。
- 队友自动拾取脚下补给箱；不捡特殊武器（特殊武器仅玩家）。
- 队友可被雾散体黑雾遮挡视野（命中率 -50%），可被裂魂者击退。
- 队友击杀计入团队分数，不计玩家个人爆头率。

### 仇恨系统（新增）

怪物目标选择规则：`得分最高的友方单位` 获得仇恨。

- 基础分 = 15m 内距离反比；
- 对该怪造成伤害者 +40 分（5 秒衰减）；
- 自爆体/裂魂者优先选择离自己最近的单位；
- 玩家始终有 +15  bias（保证"拉火车"战术由玩家主导，但队友能稳定分走一半近战怪）。

## 七、BOSS 战

### 泰坦（第 15 / 20 波）

- HP 6000（普通），体型 3m 高，弱点头部（双倍）。冲刺前摇 0.8s 有抬臂动作。

- 技能组=泰坦全增强 + 新技：

## 八、补给与特殊武器

### 波间补给（每波结束触发，15 秒窗口）

- 固定 4 个补给点位（中央平台×2、车顶×1、出发区×1），每波随机点亮其中：弹药箱×2、医疗箱×2（点位轮换，鼓励跑图）。
- 弹药箱：步枪 +90 / 手枪 +36；医疗箱：+35 HP（满血时不拾取，同现状规则）。
- 补给箱 15 秒后仍存在，直到被拾取或下一波结束；同屏上限 8。
- 沿用现有击杀掉落规则（每 5 杀医疗 / 每 3 杀弹药），但掉落物寿命从 35s 降为 20s，避免与波间补给混淆。

## 九、计分与结算

```
总分 = (击杀分 + 波次分) × 难度倍率 × 硬核加成
击杀分 = 敌人分数表（队友击杀按 60% 计入）
波次分 = 每波 300 + 无复活奖励 100（该波玩家未耗币）
BOSS 分 = 泰坦 5000 / 巨型泰坦 20000
硬核加成 = 复活币设为 0 时 ×1.5
```

结算面板：到达波次、总分、击杀/爆头率、复活币消耗数、队伍存活时长榜、用时。失败时显示"阵亡于第 N 波"并保留击杀分（用于排行榜/最佳纪录）。
