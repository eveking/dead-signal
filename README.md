# DEAD SIGNAL / 死寂信号

一款纯前端、零构建的浏览器 3D 第一人称射击生存游戏。基于 Three.js，主打「巨人城 · 30 波防守」——在一张 96×48 的长条废墟地图上，与 3 名 AI 队友并肩，靠仇恨分流、高层栈道与补给武器守住防线，直到击败第 30 波的巨型泰坦。

## 快速开始

无需 `npm install`，只要本机装有 Node.js：

```bash
node server.js
# 或双击 启动游戏.cmd
```

然后浏览器打开 **http://127.0.0.1:8080**（端口被占用时用 `PORT=8081 node server.js` 换端口）。

- `server.js` 是一个零依赖的静态文件服务器，仅做同源目录映射，游玩期间保持窗口开启即可。
- 也可以**直接双击 `index.html`** 离线运行（Three.js 走 CDN，需联网）。
- 仓库内附带 **`DEAD-SIGNAL-单文件版.html`**：把 Three.js 与全部脚本内联成单个文件，双击即可运行、便于分享。

## 游戏模式

开局在指挥中心二选一：

| 模式 | 地图 | 内容 |
|---|---|---|
| **巨人城 · 30 波防守** | 96×48 长条废墟 | 主模式：队友 + 仇恨 + 复活币 + 高层栈道 + 补给/特殊武器 + BOSS，完整走 M0–M7 玩法 |
| **隔离区 07 · 5 波练习** | 48×48 短图 | 旧玩法原样保留，无队友与复活币，用于熟悉操作 |

## 难度

| 难度 | 敌方 HP | 伤害 | 兵力 | 默认复活币 | 得分倍率 |
|---|---|---|---|---|---|
| 经典·普通 | ×1.0 | ×1.0 | ×1.0 | 30 | ×1.0 |
| 高级 | ×1.5 | ×1.3 | ×1.15 | 20 | ×1.5 |
| 噩梦 | ×2.2 | ×1.8 | ×1.35 | 10 | ×2.5 |

开局可拖动复活币滑条（0–99）；设为 **0 触发硬核模式，最终得分 ×1.5**。

## 武器与装备

五个固定槽位（`js/weapons.js` 的 `DZ.WEAPONS` 注册表驱动）：

1. **AR-7 突击步枪** — 主武器，全自动
2. **P-12 战术手枪** — 副武器
3. **M-40 破片手雷** — 投掷
4. **M-9 军刀** — 近战
5. **M-21 狙击步枪** — 开镜高伤

**特殊武器**（补给箱投放，占用 5 号狙击槽）：**R-80 火箭筒**、**M-56 加特林**。

## 核心机制

- **小队与仇恨**：3 名 AI 队友（游骑兵等分工），敌人按基础仇恨分在玩家与队友间分流，玩家不是唯一靶子。
- **濒死与复活经济**：玩家倒下进入 60 秒濒死读条，`E` 花币在前线复活点归队，读完即团队失败；`G` 传送随时自救、不花币无冷却。
- **高层可通行地图**：南端斜坡 → 装载甲板 → 车厢顶 → 冷钢色跨通道横桥 → 集装箱顶栈道，玩家不回地面即可横穿全图；怪物按地面单位规则上不来。
- **波间补给与特殊武器箱**：每波结束触发补给窗口；固定波次投放火箭筒/加特林，BOSS 击杀必掉。
- **BOSS 战**：第 15 / 20 波泰坦、第 30 波巨型泰坦，独立状态机与骨架动画。
- **计分与纪录**：结算统计最终得分、到达波次、击杀/爆头率、复活币消耗与用时，最佳纪录存于 `localStorage`。

## 敌人图鉴

经典普通难度下的 6 种常规感染者 + BOSS：

| 名称 | 代号 | 行为 |
|---|---|---|
| 步行者 | `walker` | 基础近战追击 |
| 疾行者 | `runner` | 快速骚扰 |
| 膨胀体 | `bomber` | 接近后自爆（含冲顶自爆） |
| 暴君 | `tyrant` | 重型坦克，高血量、减伤 |
| 雾散体 | `fogger` | 放雾、视野干扰 |
| 裂魂者 | `splitter` | 击退 |
| 泰坦 / 巨型泰坦 | `titan` | BOSS 状态机（实验体 T-01 / T-00，践踏 / 抬臂 / 砸地） |

## 技术栈

- **渲染**：[Three.js](https://threejs.org/) r160（CDN 引入，单文件版内联压缩版）
- **语言**：原生 JavaScript（ES2020+，无框架、无打包器、无 TypeScript）
- **服务**：Node.js 内置 `http` 模块实现的零依赖静态服务器
- **音频**：Web Audio API 程序化合成（`js/audio.js`）
- **寻路**：网格 BFS 流场，支持追玩家 / 追队友双流场与高层可走层

## 测试

`tests/` 下是页内冒烟测试脚本，通过 Chrome 远程调试端口对游戏实例做 `eval` 断言与截图，覆盖各里程碑验收点。使用前需用 `--remote-debugging-port=9223` 启动一个隔离 Chrome 并打开游戏页：

```bash
node tests/browser.cjs eval "<表达式>"   # 在页内执行并回显 JSON
node tests/browser.cjs shot <输出.png>   # 截图
```

各里程碑的专项脚本（`tmp-m3a` / `tmp-m5` / `tmp-m6` / `tmp-w` 等）保留了对应的绿色基线断言。
